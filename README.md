# mastering.wav

브라우저에서 WAV 파일을 불러와 EQ, 컴프레서, 스테레오 폭, 새추레이션과 리미터를 조절하고 결과를 WAV로 내보내는 마스터링 데모입니다.

## 실행

별도 서버 설정이나 빌드 과정이 필요하지 않습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열어 사용합니다. 오디오 데이터는 서버로 업로드되지 않고 Web Audio API를 통해 브라우저 안에서만 처리됩니다.

## 주요 기능

- 드래그 앤 드롭 또는 파일 선택으로 WAV 불러오기
- 3밴드 EQ, 컴프레서, 스테레오 폭, 새추레이션, 리미터 조절
- 원본/마스터 결과 전환 재생 및 간단한 레벨 분석
- 24-bit WAV 결과 파일 다운로드
